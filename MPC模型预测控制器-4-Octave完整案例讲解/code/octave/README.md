# MPC Octave 代码示例（修复版）

代码提取自 [DR_CAN 的 B 站动态](https://www.bilibili.com/opus/666629407425691664)，由三个文件组成：

- `MPC_Test.m`：主程序与绘图；
- `MPC_Matrices.m`：构造预测模型和二次规划矩阵；
- `Prediction.m`：求解控制序列并返回第一步输入。

运行时将三个 `.m` 文件放在同一目录，在 Octave 或 MATLAB 中执行：

```matlab
MPC_Test
```

## 修复内容

1. 将状态历史矩阵从 `n x k_steps` 修正为 `n x (k_steps+1)`，与循环中写入 `X_K(:,k+1)` 的行为一致。
2. 绘图的横坐标分别使用状态时刻 `0:k_steps` 和输入时刻 `0:k_steps-1`。
3. 状态和输入图例根据实际维度自动生成，不再固定为两个变量。
4. 对模型、权重和预测区间的矩阵尺寸增加检查。
5. 强制对称化二次规划矩阵 `H`，减小浮点误差导致求解器拒绝矩阵的风险。
6. 检查二次规划返回值；未安装 Octave `optim` 包时，对当前无约束问题使用解析回退解。
7. 将含义容易混淆的预测矩阵变量补充注释，并保留原帖算法和参数。
