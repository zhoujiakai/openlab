## Lab

### 1. 锅炉时序数据

这篇论文[1]提供了一份浙江某化工厂的锅炉运行过程中的时序数据。时序为连续的24小时x5天，采集频率为 5条/分钟，包括炉膛、水汽管道、烟气管道、风管道等位置的30个测点，传感器类型包括温度、压力、氧气含量、电流、振动等。

锅炉工艺机理，给煤机将碎煤颗粒送入炉膛（furnace）中，炉膛底部有一次风机，将细小的碎煤颗粒和循环灰吹浮至炉膛中部，较大的碎煤颗粒则落在炉膛底部和床料混在一起，炉膛两侧有二次风机，为炉膛中部的燃烧补充氧气。碎煤颗粒燃烧产生高温烟气，和炉膛顶部的汽包（Steamer Bag）进行热交换。烟气裹挟着大量循环灰，出炉膛的烟气经过旋风分离器（Left/Right Cyclone Separator）分离出部分循环灰，经过回料风（reclaimer）送回至炉膛，加大了炉膛内烟气的密度，能够增强炉膛内烟气和炉膛顶部受热面进行热交换的效率，并降低燃烧过程中NOx的生成。后续烟气还会依次与主给水管道（Mains water supply）上的过热器（High/Low temperature superheater）、省煤器（upper/lower stage economiser）以及风道上的空气预热器（Primary/Secondary air preheater）继续进行热交换，充分利用烟气中剩余的部分热量。引风机（Ventilator）在烟气管道尾部将烟气尾气抽出至烟囱（Chimneys）进行排放，并维持炉膛负压，防止炉膛回火。

论文指出，从DCS采集的原始数据存在缺失点，论文使用AR自回归模型对缺失点进行填充，预处理之后得到的这份长尾分布的真实工业数据，适合用于做异常检测、鲁棒预测等实验。

kaggle上，有实验[2、3]针对这份数据进行了时序分析、异常检测、鲁棒预测。

这个实验中，对这份原始的锅炉运行时序数据，先做了预处理，比如使用AR自回归或线形插值等方法填充缺失点。接着对时序数据进行了深入的分析，根据三西格玛原则识别数据中的异常点，通过隔离森林识别时序中的异常工况；通过相关性计算筛选出影响关键工艺指标的主成分，通过变量移位确定滞后关系，并通过XGBoost模型预测关键工艺指标的变化趋势。这些工作为后续控制模型和策略的可解释性提供了数据支撑。
